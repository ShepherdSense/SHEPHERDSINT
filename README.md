# SHEPHERDSINT

Daily open-source briefing on the Ukraine and Iran conflicts — plus a weekly emerging-technology report on Sundays.

## Live sites

- **Main site:** https://muse.ai/s/shepherdsint-xvl6gx0xfsxdxfhxn/z77D2hRvYbjgNTx7LSXDFt2U5ZQYD5BJKUYSpjezKe0
- **GitHub Pages mirror (this repo):** https://thedracospark-prog.github.io/SHEPHERDSINT/

## What's in each edition

- **Ukraine and Iran:** the day's developments, each sourced, with claims labeled by confidence.
- **Top three potential outcomes** for each conflict, with indicators that would confirm or disprove each one.
- **"What they're telling their people":** how each country's domestic and state media frames events — attributed as framing, never presented as fact.
- **Sundays:** the week's emerging technologies (AI, drones, EW, space, cyber, biotech, energy) and an assessment of what's next.

## About this repo

`index.html` is a snapshot of the current edition, refreshed each morning. The main site above is the primary home.
